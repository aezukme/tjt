# TJT Content Generator

Generate content that fits TJT.

Allowed:

* Units
* Enemies
* Bosses
* Abilities
* Waves
* Synergies
* Factions

For every generated unit include:

* Name
* Role
* Cost
* Stats
* Ability
* Upgrade path
* Synergy interactions

Avoid generic RPG designs.

Favor Legion TD style strategic roles.

Generated content must be balanced against existing units.
